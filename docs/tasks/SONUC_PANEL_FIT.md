# Panel fit ve maskot sonucu

Kesilmenin nedeni: tasarım yüksekliği native pencereye zoom uygulanmadan gönderiliyordu; kart 1.5 kat çizilirken pencere daha kısa kalıyordu. Eski frame başına yükseklik IPC'si kaldırıldı. İçerik ölçüsünden zoom + yatay fit + hitK ile tek native logical hedef hesaplanır. Kart yüksekliği resize tamamlanana kadar gerçek CSS client sınırında tutulur; genişleme sonrasında ResizeObserver tekrar ölçer. Native hedef değişmedikçe IPC yinelenmez.
