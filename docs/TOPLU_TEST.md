# Kullanıcı Toplu Kabul Test Listesi

Bu liste, kullanıcının gerçek Windows ortamında 15–20 dakika içinde uygulayabileceği teknik terimsiz kontrol adımlarını içerir.

**Ön Koşul:** Masaüstündeki **AfuNobet UI** kısayolu veya `dist/afunobet-ui-coucou.exe` çalıştırılmış olmalıdır.

---

| No | Ne Yapılacak? | Beklenen Davranış | Durum |
|:--:|---|---|:---:|
| **1** | Masaüstündeki **AfuNobet UI** kısayoluna çift tıkla. | Ekranın üst ortasında Afu karakteri ve durum kartı açılmalı. | [ ] Geçti / [ ] Kaldı |
| **2** | Kart açıkken arkadaki bir programa (Not Defteri veya Tarayıcı) tıkla ve yazı yaz. | Başka pencerede rahatça yazı yazılabilmeli, Afu klavyeyi kilitlememeli. | [ ] Geçti / [ ] Kaldı |
| **3** | Kartın çevresindeki şeffaf boşluklara tıkla. | Alttaki masaüstü simgesi veya pencere seçilmeli (boşluklar tıklamayı engellememeli). | [ ] Geçti / [ ] Kaldı |
| **4** | Ana kart açıkken **Esc** tuşuna bas veya **Küçült** düğmesine tıkla. | Karakter ekranın üstünden görev çubuğuna (saat/başlat yanına) doğru süzülmeli ve mini pet moduna geçmeli. | [ ] Geçti / [ ] Kaldı |
| **5** | Görev çubuğundaki **Mini Pet** üzerine fareyi getir. | Afu göz kırpmalı veya selam tepkisi vermeli. | [ ] Geçti / [ ] Kaldı |
| **6** | Mini Pet üzerine **tek tıkla**. | Mini pet görev çubuğundan yukarı doğru açılmalı ve ana durum kartı geri gelmeli. | [ ] Geçti / [ ] Kaldı |
| **7** | Karakterin üzerine fareyle hızlıca **3 kez tıkla**. | Karakter kısa bir baş dönmesi / şaşkınlık ifadesi göstermeli ve sonra normale dönmeli. | [ ] Geçti / [ ] Kaldı |
| **8** | Masaüstünden herhangi bir dosyayı fareyle tutup karakterin üzerine sürükleyip bırak. | Dosya adı ilgili aktif ajanın bağlamına eklenmeli. | [ ] Geçti / [ ] Kaldı |
| **9** | Ana karttaki **Ajan sekmelerine** (Codex, GLM, Gemini, OpenCode) tıkla. | Seçilen ajanın görev detayları görünmeli, çalışmayan ajanda sakin boş durum kalmalı. | [ ] Geçti / [ ] Kaldı |
| **10** | Ana karttaki **Kota durumu** bölümünü incele. | Ajanların kotaları yüzde ve kalan süre ile net görünmeli, uydurma veri yazmamalı. | [ ] Geçti / [ ] Kaldı |
| **11** | Görev paneli açıkken **GitHub servis kutucuğuna** bak. | Servis durumu (başarılı/çalışıyor/hata) doğru simgeyle görünmeli. | [ ] Geçti / [ ] Kaldı |
| **12** | Sağ alttaki sistem tepsisinde bulunan **Afu simgesine sağ tıkla**. | Türkçe menü açılmalı (Duraklat, Mini Peti Göster/Gizle, Aç, Çıkış). | [ ] Geçti / [ ] Kaldı |
| **13** | Tepsi menüsünden **"Mini Peti Gizle"** seçeneğini seç. | Görev çubuğundaki pet kaybolmalı; tepsi simgesine basınca ana kart tekrar açılabilmeli. | [ ] Geçti / [ ] Kaldı |
| **14** | Tepsi menüsünden **"Bildirimleri Duraklat"** seçeneğini aç. | Bildirim sesleri ve pencereleri duraklamalı, arka plan takibi sessizce sürmeli. | [ ] Geçti / [ ] Kaldı |
| **15** | Bir ajan onay istediğinde açılan **soru kartını** incele. | Kritik işlem sorusu ekranda net görünmeli; "Onayla" veya "Reddet" seçimiyle ilerlenmeli. | [ ] Geçti / [ ] Kaldı |
| **16** | Bir görev tamamlandığında veya hata olduğunda sistemi dinle. | Kısa ve rahatsız etmeyen bir bildirim sesi duyulmalı. | [ ] Geçti / [ ] Kaldı |
| **17** | Tam ekran bir video (örneğin YouTube) veya oyun aç. | Pet ve kart tam ekran görüntünün üzerine taşmamalı, videoyu kapatmamalı. | [ ] Geçti / [ ] Kaldı |
| **18** | Uygulamayı 10 dakika boyunca açık bırak ve Görev Yöneticisi'ne bak. | İşlemci (CPU) kullanımı %0-%1 seviyesinde kalmalı ve siyah boş terminal pencereleri açılmamalı. | [ ] Geçti / [ ] Kaldı |
| **19** | Tepsi menüsünden **"Çıkış"** seçeneğine tıkla. | Uygulama arkada yetim süreç veya kilitli dosya bırakmadan tamamen kapanmalı. | [ ] Geçti / [ ] Kaldı |
