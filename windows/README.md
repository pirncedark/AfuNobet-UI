# AfuNobet-UI Windows

Tauri 2, TypeScript ve Vite. Bu dizinde npm --offline test, npm --offline run
build, cargo test --offline, npm --offline run screenshots ve npm --offline
run pack komutlari kullanilir. CARGO_NET_OFFLINE=true ile calisin.

Kaynak ve teslim bilgileri ust dizindeki README.md ve AFU_CHANGES.md
belgelerindedir. Test fixture dosyalari production build girisi degildir.
